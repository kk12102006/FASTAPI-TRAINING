-> pyhton has asyncio
-> nodejs uses library called libuv(c library) (it is called event loop)
-> Fastapi- ASGI based web dev framework
          - Starlette(framework to run asynconus) uvloop sits on libuv 
          - pydantic is used for data validation and serialization framework
-> uvicorn(it is server and also cli(means command)) runs the starlette
-> uvloop 2 to 4 times faster than the eventloop
   (pyhton object convert to json then it is called serialization and the reverse is deserialization)
-> HTTP methods are called verbs and url is called noun
 -> POST,GET,PUT,DELETE are operations of path 


-> It is used to run the fast api -  py -m uvicorn main:app --reload
   then you will get a link to paste in browser
   for that link add /docs to open swagger(used for documentation and testing)


-> Get /tickets read all tickets
-> GET /tickets/1 read ticket with id 1
-> POST /ticket/1 create a ticket
-> DELETE /tickets/1 delete a ticket (is ticket not found result wil be "resource not found"

-> Run API using uvicorn server- uvicorn main:app --reload
